# 🎮 2D Top-Down Shooter Game

A fun local multiplayer 2D top-down shooter game built with HTML5, CSS, and JavaScript.

## 🚀 How to Play

### Installation & Running:
1. **Download** this repository and extract the files
2. **Open** `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari)
3. **That's it!** No installation required - just play locally!

## 👥 Game Modes

### Single Player:
- Use **WASD** or **Arrow Keys** to move
- Click to shoot at enemies
- Collect coins and power-ups
- Defeat waves of enemies

### Two Player (Local):
- **Player 1**: WASD + Mouse to shoot
- **Player 2**: Arrow Keys + Numpad/Number keys to shoot

## 🎯 Features

- ⚔️ Multiple enemy types with different behaviors
- 💰 Collectible coins for score
- ⭐ Power-ups (speed boost, weapon upgrades)
- 🏆 Score tracking and high score system
- 🎨 Simple pixel-style graphics
- 🔊 Sound effects (browser-based)

## ⌨️ Controls

### Player 1:
- **WASD** / **Arrow Keys** - Move character
- **Mouse Click** - Shoot weapon

### Player 2:
- **Arrow Keys** - Move character  
- **Numpad 0/Numbers** or **Number Row** - Shoot

## 🛠️ Tech Stack

- HTML5 Canvas for rendering
- Vanilla JavaScript (ES6+)
- CSS3 styling
- LocalStorage for high scores
- No external dependencies!

## 🎮 Game Rules

1. **Objective**: Survive as long as possible while defeating enemies
2. **Score**: Earn points by killing enemies and collecting coins
3. **Waves**: Each wave gets harder with more and stronger enemies
4. **Game Over**: When your health reaches 0
5. **Win Condition**: Reach the highest score before time runs out

## 🌟 Tips & Tricks

- Collect power-ups strategically
- Stay near walls for cover when possible
- Save ammo for tougher enemies
- Coordinate with partner in 2-player mode
- Use corners to trap enemies
